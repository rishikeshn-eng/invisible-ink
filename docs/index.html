There may be text in here your eyes can't see.

A web page, an email, a PDF, a pasted string — any of them can carry instructions or data hidden in Unicode that renders as nothing to a human but reads loud and clear to a model: invisible tag characters, bidi overrides, variation-selector payloads, zero-width runs, homoglyph spoofs. invisible-ink finds it, decodes it, and strips it — without mangling real Arabic, Hindi, Thai, or emoji.

Evaluation

Catches the attacks. Keeps the languages.

A sanitiser that strips all non-ASCII would catch every attack and destroy the world's text. The hard part is precision on real multilingual content, so invisible-ink is calibrated against FLORES-200: 1,012 professionally-translated sentences in each of 204 languages.

Under the hood

Scan, decode, sanitise.

No model, no network. The detection rules come from the Unicode Character Database, and the context logic is tuned so legitimate international typography (Indic/Arabic joiners, Thai word breaks, CJK variation selectors, emoji ZWJ) is never mistaken for an attack.

01

Classify every code point

Against UCD-generated tables: default-ignorable, bidi controls, variation selectors, scripts, and a 6,712-entry confusables map.

02

Judge in context

A zero-width joiner inside Devanagari is typography; the same character between two Latin letters is smuggling. Script context decides.

03

Decode the payload

Tag characters map back to ASCII; variation-selector runs decode to bytes. The hidden message is recovered, not just flagged.

04

Sanitise, losslessly

Strip the smuggling vectors while leaving legitimate multilingual text byte-for-byte intact.

sanitise untrusted input before it reaches your model
# a tool returns web/email/document text — clean it before the model trusts it
from invisible_ink import scan, sanitize

report = scan(tool_output)
if report.verdict == "dangerous":
    log("hidden payload:", report.hidden_text)   # the decoded instruction

clean = sanitize(tool_output).cleaned             # safe to pass on; languages intact

Ships as a library and a CLI: invisible-ink --reveal "$text" prints the hidden payload; --clean prints the sanitised text.

invisible-ink Source & benchmarks Built by Rishikesh Nair · MIT licensed

invisible-ink detects known Unicode smuggling techniques and is a defence-in-depth layer, not a guarantee; new encodings can be devised, and the confusables signal is inherently heuristic on mixed-script text. It reasons about characters, not meaning, and should sit alongside input provenance and least-privilege execution. The live demo runs the exact published scanner in your browser via Pyodide; all figures are reproducible from the repo, and the character tables are generated from the public Unicode Character Database. Precision is measured on the FLORES-200 dataset.
